# PRD Ringkas — ETOS Pembinaan Management System

## Visi
Satu sistem untuk merencanakan, menjalankan, memonitor, dan mengevaluasi seluruh perjalanan pembinaan Etoser.

## Masalah
Proses saat ini tersebar di Form, Sheet, Drive, file wilayah, file peserta, dan checklist manual.

## Prinsip
1. Activity-driven, bukan hard-coded per kegiatan.
2. Satu sumber data.
3. Monitoring berbasis pengecualian: sistem menunjukkan siapa yang belum, terlambat, atau perlu tindak lanjut.
4. Mobile-first untuk Etoser dan Fasilitator.
5. Role-based access control.

## Role
- Tim Pusat / Superadmin
- PIC Program
- Fasilitator Wilayah
- Etoser

## Alur inti
Program → Activity → Target → Requirement → Assignment → Attendance/Submission → Review → Result → Evaluation → Credit Perform.

## MVP
Auth, user/wilayah/angkatan, activity management, dynamic assignment, agenda, presensi, worksheet/submission, jurnal, dashboard Etoser, dashboard Fasilitator, Command Center Tim Pusat, monitoring matrix, profil 360°, deadline/notifikasi, search/filter, export.
