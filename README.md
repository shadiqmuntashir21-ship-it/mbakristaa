# ETOS Pembinaan Management System

Satu ruang kerja digital untuk seluruh perjalanan pembinaan Etoser.

## Fitur MVP
- Landing page dan demo interaktif tiga role
- Supabase Auth + SSR session
- Role-based workspace: Tim Pusat, Fasilitator, Etoser
- Activity-driven data model
- Dynamic requirement & assignment engine
- Monitoring matrix
- Profil & progres Etoser
- Presensi, submission, jurnal, laporan bulanan, credit perform schema
- RLS dan private storage

## Stack
Next.js 16.4, React 19.3, Supabase/PostgreSQL, Vercel.
